## Project

Arcade Vault: an online platform for playing games and competing for the highest score. Currently a fresh Create Next App scaffold (`app/layout.tsx`, `app/page.tsx` are still boilerplate).

Development follows Spec Driven Design (SDD) using the `/spec` and `/spec-impl` skills from https://github.com/Klerith/fernando-skills (install with `npx skills@latest add Klerith/fernando-skills`). Write a spec before implementing a feature.

No test framework is configured yet.

## Skills
Always use /frontend-design to design the user interface.

## Stack and configuration

- Next.js 16.4 (App Router, `app/`), React 19.3, TypeScript strict, Tailwind CSS v4.
- Next.js APIs differ from training data: check `node_modules/next/dist/docs/` (`01-app/`, `03-architecture/`) before using any Next API.
- `next.config.ts` enables `cacheComponents` and `partialPrefetching` (caching/prerendering behavior differs from older Next versions, so read the cache components docs before fetching data or using dynamic APIs) and `experimental.agentFeedback`.
- Tailwind v4 is CSS-first: no `tailwind.config.*`. Theme tokens live in `@theme inline` in `app/globals.css`, and CSS is processed through the `@tailwindcss/turbopack` loader configured in `next.config.ts` (not PostCSS).
- Path alias `@/*` maps to the repo root.
- Route-typed helpers such as `LayoutProps<"/">` are global types generated by Next (see `app/layout.tsx`).
